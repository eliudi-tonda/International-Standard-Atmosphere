# International-Standard-Atmosphere
Using python to calculate the values of pressure, temperature , density and velocity of air across various heights above sea level

## Applications
    -Aircraft performance analysis
    -Flight mechanics
    -Aerodynamics
    -Propulsion

## Language and libraries used
    -Python3
      - math
      -sys

## How to run
    - open terminal ( make sure you have git installed to your machine)
    - run
        git clone https://github.com/eliudi-tonda/International-Standard-Atmosphere.git'
        cd International-Standard-Atmosphere
        ls (you will see the list of files)
        python isa.py

## Atmospheric layers covered
  - Troposphere
  - Tropopause
  - Lower stratosphere
  - Upper stratosphere
  - Stratopause
  - Lower mesosphere
  - Upper mesosphere
  - Uppermost atmosphere
